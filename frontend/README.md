# Frontend

The proposal specifies a Next.js (React) web application with Plotly visualizations.

Planned interface areas:

- Natural-language chat and clarification/refusal states.
- Evidence panel showing SQL, definitions, simulation settings or optimizer model card.
- Simulation fan charts, parameter sliders and scenario presets.
- Optimizer approval screen, plan table, binding constraints, cost-service curve and infeasibility explanation.
- One-page decision memo export and approval history.

Initialize the Next.js scaffold when the team agrees the API response contracts in the week-3 integration milestone. Keep the UI aligned with those contracts rather than inventing separate response shapes.
